How LLMs Work

So many good explanations exist already that there’s no point in going through all the theory here. Two notable examples:

  • Beautifully animated short intro by 3Blue1Brown
  • In-depth course by Andrej Karpathy

As mentioned above, during the course of this project we’ll mess with the residual stream, so let’s focus on what it is and how to understand it intuitively.

An LLM processes the input prompt in 3 stages:

  1. Tokenization - takes a sentence, such as “Augsburg is a city in Bavaria”, splits it into a list of subword chunks, for example ['A', 'ugs', 'burg', 'Ġis', 'Ġa', 'Ġcity', 'Ġin', 'ĠBav', 'aria'] (the weird Ġ character is a replacement for a leading space in the Llama tokenizer, it does not matter, move on), and maps them to integer token IDs.
  2. Embedding - translates the kk input tokens into a k×dk \times d matrix, where dd is the model dimension.
  3. Prefill - applies the sequence of Transformer layers (self-attention + MLP, labeled “Transformer + MLP” in the diagram below) to the embedding matrix.
  4. Here the model would start autoregressively generating the answer, but it’s not really relevant for this project so we’ll skip it.

Residual Stream

More formally (but still comfortably handwavey), during the prefill each LLM layer performs the following:

hi+1=hi+Fi(hi)h_{i+1} = h_i + F_i(h_i)

where h1h_1 is the initial token embeddings matrix and FiF_i is the ii-th layer. Notice the ++ sign: instead of overwriting the matrix, each layer adds a residual update to the existing representation.

While every token row has its own residual stream, for the purpose of understanding and modifying the LLM’s behavior, the last row of the matrix—corresponding to the last prompt token—is of special interest to us. Because causal attention only looks backward, the LLM is trained to aggregate the full context of the prompt into that final row right before predicting the next token. Let’s denote the last row of the hih_i matrix as xix_i.

The sequence of vectors x1,…,xnx_1, \ldots, x_{n} across the model’s layers is our “residual stream”.

Intuitive Understanding

Because each layer reads from and adds to the same vector space, the residual stream encodes a progressively more sophisticated understanding of the prompt as data is pushed through subsequent layers. It turns out that different directions in this shared “meaning” space correspond to different concepts in human language.

If that’s true, we can expect the following hypotheses to hold:

  • The actual language (English, Polish, German…) should be abstracted away after a few initial layers because the middle part of the network operates on concepts rather than words.
  • Refusal to follow instructions should be a direction in the meaning space. By ablating that direction, we should make the LLM less patronizing with its refusals. (Well, technically we know that because there’s a paper from 2024 proving this, but let’s pretend we don’t know that.)

In the next parts, we’ll test these hypotheses.
