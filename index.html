Krzysztof Chrobak — Personal Space

Role: Software Engineer / Web Developer
Location: kchrobak.pl

Welcome to my personal computing environment. This website is styled after the legendary Windows 95 operating system, built entirely from scratch using Vanilla TypeScript and pure CSS, free of frontend frameworks.

System Directory Map

  • info.txt
    You are here. This page displays information about the system and its author, rendered directly from Markdown source files.

  • articles/
    A folder containing technical notes, software architecture logs, and general reflections. I publish about two articles a year in Markdown.

  • utils/
    A directory housing experimental web technology utilities and interactive canvas animations.

Operating System Features

  • Theme Control
    Use the View application menu at the top of the window to switch between Light Theme (classic gray), Dark Theme (midnight classic), or your System Default.

  • Notepad Shell
    Markdown documents and text files are presented in a high-fidelity retro editor frame complete with bevel highlights and functional sidebar navigators.

Note: This website is under active development. Content items and utility pages are structured as obvious high-fidelity placeholders. Feel free to explore.
